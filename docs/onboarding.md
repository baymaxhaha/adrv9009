# 新人入门指南（C 语言）

## 1. 第一天目标

- 拉取代码并成功执行 `make build && make run`。
- 阅读 `README.md`，理解目录职责。
- 提交一个小 PR（如文档修正）。

## 2. 先理解这三层

1. **入口层**：`src/main.c`，关注程序启动流程。
2. **构建层**：`Makefile`，关注编译参数与目标。
3. **质量层**：`tests/smoke_test.sh` + CI，关注“改完如何证明没坏”。

## 3. 每次改动的最小自检

1. `make clean && make build`
2. `make run`
3. `make test`

## 4. 代码评审关注点

- 命名是否表达清晰
- 函数是否短小、职责单一
- 错误路径是否处理
- 日志是否能定位问题
- 是否补充必要注释与文档

## 5. 首周建议

- Day 1：跑通项目 + 文档 PR
- Day 2：走读入口与构建流程
- Day 3：修一个低风险问题并补测试
- Day 4：做一个小功能切片
- Day 5：输出学习总结与问题清单
